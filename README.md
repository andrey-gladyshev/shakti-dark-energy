# Shakti Dark Energy

Численные скрипты для статьи:

**"Квантовое происхождение начальной флуктуации тёмной энергии: 
численное следствие постулированной массы m_φ = H/2 
в пространстве де Ситтера"**

Андрей Гладышев (Независимый исследователь)

## Краткое описание

Однопараметрическая феноменологическая модель тёмной энергии 
с нормировкой α₀ = 1. При постулированных массах m_Σ = H, 
m_φ = H/2 фитовое начальное условие x_i = 0.168721 численно 
близко к амплитуде Банча–Дэвиса δφ/H = 0.168973 
(коэффициент c = 0.9985, отклонение 0.15%).
